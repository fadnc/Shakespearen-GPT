# Shakespearen-GPT
A Model that outputs texts in as if shakespeare wrote it

What we are building
We'll call our model ShakespeareGPT.

The model should eventually be able to take an input such as:
O, my beloved,

And generate something resembling:
O, my beloved, wherefore dost thou weep?
The moon hath cast her shadow on thy heart,
And stars shall mourn until the break of day.

This is an illustrative target, not an actual trained model output.
